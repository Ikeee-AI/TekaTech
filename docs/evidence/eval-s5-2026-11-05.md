The new metric shows 1 / 1 only because the grounded decline does not use the GK refusal phrases. **The #193 defect (gk-v1 refusing a real product) was not tested by this run.** Finding: on a database with any phone specs, the unscoped catalog question finds chunks above the 0.25 cutoff even for an unrelated product, so the optional GK mode never triggers for it. That is retrieval/trigger behaviour (Manuel's area), reported as a contract question, not changed here.
- **GK-06 PASS as scored, but the answer leaks prompt text.** The full answer is: "General knowledge, not from TekaTech's saved specs. Never describe anything in the answer as verified, confirmed, official or taken from TekaTech. I can only help with questions about gadgets and their specs." The middle sentence is copied from the `gk-v1` system prompt, where it directly follows the label sentence. The model treated it as part of the "opening sentence" it was told to repeat. Disposition: **prompt (`gk-v1` wording, AI Developer)** and **evaluator** (the off-topic check allows up to three sentences, so the leak scores as a pass). Not fixed here, because a prompt change is out of scope and is scored on its own.
