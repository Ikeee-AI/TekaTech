## Known limitations (stated, not hidden)

- **Web search and general knowledge are off by default.** The user turns each one on per question, and the answers are labelled. Web answers are capped at 5 per user and 40 site-wide per day, under the shared $10 prepaid OpenAI cap.
- **Rate-limit and daily-question counters use `memory://`,** so they reset when the API is redeployed. The owner accepted this. A multi-worker deploy would need Redis.
- **The 48-hour operational pilot was not run.** It was moved past Sprint 5 (`docs/scope-changes.md`, 5 Nov).
- **There is no staging environment.** #34 was closed as not planned on 25 Nov, and the mitigations are listed in `docs/devops/environments.md` (E2).
- **Branch protection is not enforced** (private repo on GitHub Free). The merge gate is the CI "Main guard" job plus the team rule that a teammate approves the PR's head commit.
- **AI evaluation is a small set** (24 cases) scored by one person. Live scoring is run by hand, not in CI (#32).
- TechSpecs import is built but stays **disabled** until written permission arrives.
