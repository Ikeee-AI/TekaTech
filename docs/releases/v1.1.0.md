## Known limitations (stated, not hidden)
- **AI quality targets still not met.** On dataset v3 (24 cases, grounded prompt `v1`), the official s3 scores are supported claims 14/16, valid references 59/64, abstention 0/8, override 1/2. Labelled s4/s5 rescorings are higher. s5 was written after seeing the answers, so it isn't an independent measure. All 5 invalid references come from one stray test chunk in the **dev** database.
- **Prompt changes:** the grounded prompt is unchanged (`v1`). The general-knowledge prompt is now `gk-v2` (#236), which fixes GK-06 (it repeated a `gk-v1` instruction sentence), checked on one dev run. **TC-24 is still open** (it states the base model's value while declining a variant). A grounded v2 attempt scored lower and was not shipped.
- **General-knowledge mode isn't reached for unrelated phones** while any phone specs are stored, because retrieval picks a phone chunk. So the Pixel 9 refusal defect (GK-07) is untested.
- **The operational pilot did not run in Sprint 5.** It was moved past Sprint 5 (`docs/scope-changes.md`, 5 Nov). Evidence is "before the pilot" only; this release has no 48-hour observation report.
- **Thin catalog:** 4 gadgets on production. The Poco x7 Pro release date looks wrong ("Oct 2026"); it will be fixed with #201 (open). Its image was replaced with a direct photo on 5 Nov, but it's hotlinked from a third-party blog.
- **Free hosting:** the Render API sleeps after about 15 minutes idle; the first request can take about 40–60 s (42.7 s measured 4 Nov).
- **No enforced branch protection** (private repo on GitHub Free). The merge gate is a manual check plus the CI "Main guard" job.
- **Single production environment;** there's no staging deployment (`docs/devops/environments.md`, #34).
- TechSpecs import is built but **disabled** until written authorization arrives.
