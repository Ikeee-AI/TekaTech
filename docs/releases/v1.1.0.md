## Known limitations (stated, not hidden)
- **AI quality targets still not met.** On dataset v3 (24 cases), the official s3 scores are supported claims 14/16, valid references 59/64, abstention 0/8, override 1/2. Labelled s4/s5 rescorings are higher; s5 was written after seeing the answers, so it isn't an independent measure. All 5 invalid references come from one stray test chunk in the **dev** database. Open prompt defects: TC-24 (states the base model's value while declining a variant) and GK-06 (repeats a `gk-v1` instruction sentence). No prompt change in this release.
- **General-knowledge mode isn't reached for unrelated phones** while any phone specs are stored (retrieval picks a phone chunk). The Pixel 9 refusal defect (GK-07) is therefore untested.
- **The operational pilot did not run in Sprint 5.** It was moved past Sprint 5 (`docs/scope-changes.md`, 5 Nov). Evidence is "before the pilot" only; there's no 48-hour observation report in this release.
- **Thin catalog:** 4 gadgets on production; the Poco x7 Pro release date looks wrong ("Oct 2026"), to be fixed with #201. The Poco image is hotlinked from a third-party site.
- **Free hosting:** the Render API sleeps after about 15 minutes idle; the first request can take about 40–60 s (42.7 s measured 4 Nov).
- **No enforced branch protection** (private repo on GitHub Free). The merge gate is a manual check plus the CI "Main guard" job.
- **Single production environment;** there's no staging deployment (`docs/devops/environments.md`, #34).
- TechSpecs import is built but **disabled** until written authorization arrives.
